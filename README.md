# 🛍️ Retail Store Performance Dashboard

## 📌 Overview

The Retail Store Performance Dashboard is a full-stack web application designed to monitor and analyze retail sales performance. It will provide key sales metrics, interactive charts, filtering options, and transaction reports.

**🚧 Project Status:** Initialization

## ✨ Planned Features

- 📊 Dashboard cards for Total Sales, Number of Transactions, and Average Basket Value.
- 🏬 Sales analysis by store and product category.
- 📈 Daily, weekly, and monthly sales charts.
- 🔎 Date range and store filters.
- 📋 Searchable transaction table with pagination.
- 📥 Export reports to CSV.


## 🗄️ Database Design

The project will use three primary tables:

| Table | Purpose |
|---|---|
| `DemoCustomer` | Stores customer information. |
| `DemoStore` | Stores retail store information. |
| `DemoProduct` | Stores product and category information. |
| `DemoSales` | Stores sales records. |
| `DemoTransactions` | Stores sales transactions. |


## 🛠️ Technology Stack

- **Frontend:** Angular
- **Backend:** .Net Core
- **Database:** Microsoft SQL Server
- **API:** REST
- **API Documentation:** Swagger / OpenAPI
- **Version Control:** Git
